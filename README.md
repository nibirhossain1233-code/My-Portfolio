# Figma Portfolio starter

## Setup
1. Install Node.js 20+.
2. Extract this project.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Important
- The design uses the supplied Figma frame as visual reference: dark #111111 background, Lato typography, orange gradient accents, and a centered 1280px content container.
- Replace the sample portfolio name, copy, contact information, and project thumbnails with your own content.
- The Figma image URLs in this starter are temporary Figma asset URLs. Download/export the original images from Figma and place them in `public/images/`, then update the `src` values to local paths.
- The contact form is frontend-only demo behavior. Connect it to your API before production.
- Add your CV at `public/cv.pdf`.
